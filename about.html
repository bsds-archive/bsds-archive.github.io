Home · About Us

Built by students,
for students.

This archive started as a simple idea: every semester's notes, papers, and dates shouldn't be scattered across a dozen group chats. So we built one place for all of it — and kept building.

Credits

Who made this, and how.

Built with Claude

The site's code — structure, styling, the interactive drawer, and the in-browser PDF viewer — was built with Claude, Anthropic's AI assistant, directed and edited by our team.

Maintained by us

The BSDS course student-run project, kept up to date by students itself. Contributions welcome!, CR, Admin, any student interested in helping is heartly welcomed!

Open & editable

Every page is plain HTML/CSS/JS with no build step — anyone on the team can open a file, edit it, and see the change immediately. See the comments in each file for how.

Always growing

Semester I is live; the rest are on their way. Announcements, syllabi, timetables and calendars get added semester by semester. Therefore we require the support of the entire BSDS community to keep this project alive and thriving.

Open source

The full source is on GitHub — browse the code, file an issue, or send a pull request if you want to add something yourself.

From the batch before us

Our seniors built something similar for their own batch — worth a look for anything from earlier years.
